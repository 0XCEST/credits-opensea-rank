\# ⚡ Credits Rarity Rank for OpenSea



A lightweight, zero-latency Chrome extension that overlays official rarity rankings, scores, and rare eights patterns on \[Jack Butcher's Credits](https://jack.art/credits) NFTs directly on OpenSea.



Built by \[@CEST\_nft](https://x.com/CEST\_nft).



\---



\## 🌟 Features



\- \*\*Instant Rarity Badges:\*\* View live rarity rank (`#1` to `#122,154`) and official score on collection grid cards and profile listings.

\- \*\*Rarity Tier Styling:\*\*

&#x20; - 👑 \*\*Mythic (Top 100):\*\* Golden amber glow.

&#x20; - 🟣 \*\*Legendary (Top 1,000):\*\* Deep purple badge.

&#x20; - 🔵 \*\*Rare (Top 5,000):\*\* Electric blue badge.

&#x20; - ⚪ \*\*Standard:\*\* Clean cyan border.

\- \*\*Eights Detection:\*\* Instant identification of rare mathematical 8-patterns:

&#x20; - 🥉 `3×8s` (Bronze)

&#x20; - 🥈 `4×8s` (Silver)

&#x20; - 👑 `5×8s+` (Ultra Rare Gold)

\- \*\*Zero API Latency:\*\* Uses a bundled, optimized local database (`ranks.json`) for instant rendering without rate limits.
